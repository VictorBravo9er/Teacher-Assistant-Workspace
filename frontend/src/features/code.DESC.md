# Feature Modules — `src/features/`

This directory groups domain-specific UI features, business workflows, and interactive modals into modular subdomains:

- [`account/`](file:///home/victor/antigravity/Teacher-Assistant-Workspace/frontend/src/features/account): User account settings, subscription management, and educator profile configurations.
- [`ai-assistant/`](file:///home/victor/antigravity/Teacher-Assistant-Workspace/frontend/src/features/ai-assistant): AI pedagogical chat interface, autonomous rubric diagnostic diff review, and dynamic analytical chart widgets.
- [`classroom/`](file:///home/victor/antigravity/Teacher-Assistant-Workspace/frontend/src/features/classroom): Classroom profile configuration, curriculum material management, rubric builders, class creation modals, and gradebook matrix grids.
- [`students/`](file:///home/victor/antigravity/Teacher-Assistant-Workspace/frontend/src/features/students): Student roster management, individual portfolio modal, student submission upload, rubric grading reviews, attendance logging, and parent report cards.
